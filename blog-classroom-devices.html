Building 3D labs that run on a five-year-old school laptop

Most school computers are not gaming rigs. If a 3D model needs a dedicated graphics card to run smoothly, it's not going to get used in an actual classroom.

Designing for the lowest common device

We test every model against older, low-spec laptops before it ships — not high-end development machines. If it stutters there, it doesn't go live.

That constraint shapes a lot of decisions: simpler geometry, fewer simultaneous light sources, and careful control over how many objects are rendered on screen at once.

No installs, no plugins

Everything runs directly in the browser using standard web technology. There's nothing for an IT administrator to install, approve, or maintain across a school's computer lab — a link is enough.

What's next

We're currently working on an offline mode for schools with unreliable internet access, so a lesson can be pre-loaded once and used without a live connection during class.
