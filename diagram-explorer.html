Reusable Tool

Click any part of a diagram to learn what it is.

A generic hotspot system — drop in any image (a plant cell, a circuit, a map, an engine), mark the parts, and clicking one reveals its name, a description, and a close-up image if you have one. This page ships with a placeholder demo so you can see it working, plus everything you need to swap in your own diagram.

How to make this your own

Everything here is driven by one JavaScript config near the bottom of this file — DIAGRAMS. Each diagram is an image plus a list of hotspots, each hotspot a percentage position (so it stays aligned at any screen size), a label, a description, and an optional close-up image.

Turn on Placement helper above, then click anywhere on the image — it copies the exact xPercent / yPercent for that spot to your clipboard, ready to paste into a new hotspot.

DIAGRAMS.push({
  id: 'plant-cell',
  label: 'Plant Cell',
  image: 'images/plant-cell.jpg',   // any image path or URL
  hotspots: [
    {
      xPercent: 22.5, yPercent: 38.0,  // from the placement helper
      label: 'Cell Wall',
      description: 'A rigid outer layer made of cellulose that gives the '
                  + 'cell its shape and protects it from bursting.',
      zoomImage: 'images/cell-wall-closeup.jpg'   // optional — omit if you don't have one
    },
    { xPercent: 50, yPercent: 50, label: 'Nucleus', description: '...' }
  ]
});

That's it — add as many diagrams and hotspots as you like, and they'll show up in the dropdown above automatically.
