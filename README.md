# 🌌 Graviton Academy

Interactive 3D science learning platform for **CBSE Grades 9–12**, with additional **NEET and IIT-JEE** learning tracks.

🌐 **Live:** https://sumitkumarkucheria.github.io/Graviton_academy/

---

## 🚀 Overview

Graviton Academy is a browser-based educational platform focused on interactive visualization of Physics, Chemistry, and Biology concepts.

The project uses interactive 3D models and simulations to represent concepts that are difficult to understand through static diagrams.

### Current Features

* Physics, Chemistry & Biology content
* Grade 9–12 curriculum structure
* NEET & IIT-JEE tracks
* Interactive 3D science models
* Atom Explorer
* Molecule Builder
* DNA Double Helix
* Interactive science labs
* Diagram Explorer
* Periodic Table
* Previous-paper resources

## ▶️ Run Locally

Clone:

```bash
git clone https://github.com/sumitkumarkucheria/Graviton_academy.git
cd Graviton_academy
```

Run a local HTTP server:

```bash
python -m http.server 8000
```

Open:

```text
http://localhost:8000
```
