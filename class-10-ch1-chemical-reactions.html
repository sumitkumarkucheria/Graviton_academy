Balancing guide — the 3-step workflow

Law of Conservation of Mass

Mass can neither be created nor destroyed in a chemical reaction — everything that goes in as a reactant has to come out as a product.

Atomic equality

The number of atoms of every element must be equal on both sides of the equation. That's the entire job of "balancing."

Mg + O2 → MgO

Magnesium and oxygen (reactants) combine to form magnesium oxide (product) — but as written, this equation isn't balanced yet.

Step 1

Inventory and box the elements

List the atom count for every element on the reactant side and the product side.

ElementReactantsProducts

Step 2

Balance via the compound with the most atoms

Start with the compound that has the highest atom count — here, Fe3O4 — and work outward: 3Fe + H2O → Fe3O4 + H2, then 4Fe + 4H2O → Fe3O4 + 4H2.

Step 3

Final check and state symbols

Verify the atom counts match, then add physical states — (s), (l), (g), (aq).

Interactive practice — balance it yourself

Fill in the coefficients, check your answer, or reveal the solution if you get stuck.

1. Hydrogen + Chlorine → Hydrogen chloride

H2 + Cl2 → HCl
H2 + Cl2 → HCl
Answer
H2 + Cl2 → 2HCl

2. Barium chloride + Aluminium sulphate → Barium sulphate + Aluminium chloride

BaCl2 + Al2(SO4)3 → BaSO4 + AlCl3
BaCl2 + Al2(SO4)3 → BaSO4 + AlCl3
Answer
3BaCl2 + Al2(SO4)3 → 3BaSO4 + 2AlCl3

3. Sodium + Water → Sodium hydroxide + Hydrogen

Na + H2O → NaOH + H2
Na + H2O → NaOH + H2
Answer
2Na + 2H2O → 2NaOH + H2

Now write the balanced equations with state symbols:

4. Barium chloride + Sodium sulphate

Solutions of barium chloride and sodium sulphate in water react to give insoluble barium sulphate and a solution of sodium chloride.

BaCl2 + Na2SO4 → BaSO4 + 2NaCl
Answer
BaCl2 (aq) + Na2SO4 (aq) → BaSO4 (s) + 2NaCl (aq)

(aq) = aqueous solution  |  (s) = solid

5. Sodium hydroxide + Hydrochloric acid

Sodium hydroxide solution reacts with hydrochloric acid solution to produce sodium chloride solution and water.

NaOH + HCl → NaCl + H2O
Answer
NaOH (aq) + HCl (aq) → NaCl (aq) + H2O (l)

(aq) = aqueous solution  |  (l) = liquid

(ii) NaOH (aq) + HCl (aq) → NaCl (aq) + H2O (l)
